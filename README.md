# Kvantfüüsika mäng & simulatsioon

Lihtne staatiline veebirakendus kvantfüüsika õppimiseks. Avage `index.html` oma brauseris.

Failid:
- `index.html` — põhileht ja UI
- `css/style.css` — stiilid
- `js/app.js` — simulatsioonide ja interaktiivsuse loogika

Käivitus:
1. Avage [index.html](index.html) oma brauseris (topeltklõps või lohistage brauseriaknasse).
2. Valige vaheleht `Simulatsioonid` ja katsetage Blochi sfääri ja topel-lõhe simulatsioone.

See on kerge ja jagatav failihulk — soovite, saan lisada täiendavaid ülesandeid, selgitavat sisu või lauamängu elemente.
